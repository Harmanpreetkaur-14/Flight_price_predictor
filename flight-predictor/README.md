# SkyFare — Flight Price Predictor
## Complete Deployment Guide

---

## PROJECT STRUCTURE

```
flight-predictor/
├── app.py               ← Flask backend + DB + prediction API
├── save_model.py        ← Run once to export model.pkl
├── model.pkl            ← Generated by save_model.py  (you create this)
├── model_columns.pkl    ← Generated by save_model.py  (you create this)
├── requirements.txt
├── Procfile             ← For Render / Railway deployment
├── templates/
│   └── index.html       ← Full frontend UI
└── instance/
    └── predictions.db   ← SQLite DB (auto-created on first run)
```

---

## STEP 1 — EXPORT YOUR TRAINED MODEL

Run this inside the folder where your notebook lives:

```bash
python save_model.py
```

This creates **model.pkl** and **model_columns.pkl**.
Copy both into your `flight-predictor/` folder:

```bash
cp model.pkl       flight-predictor/
cp model_columns.pkl flight-predictor/
```

---

## STEP 2 — RUN LOCALLY

```bash
cd flight-predictor
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000 in your browser.

The SQLite database `instance/predictions.db` is created automatically.

---

## STEP 3 — SWITCH TO POSTGRESQL (production)

1. Install PostgreSQL locally or use a free cloud DB (Neon, Supabase, Railway).

2. Create a `.env` file:
```
DATABASE_URL=postgresql://username:password@host:5432/flightdb
```

3. Update `app.py` line:
```python
from dotenv import load_dotenv
load_dotenv()
app.config['SQLALCHEMY_DATABASE_URI'] = os.getenv('DATABASE_URL', 'sqlite:///predictions.db')
```

4. Create tables:
```bash
python -c "from app import app, db; app.app_context().__enter__(); db.create_all()"
```

---

## STEP 4 — DEPLOY TO RENDER (free tier)

1. Push your project to GitHub:
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/flight-predictor.git
git push -u origin main
```

2. Go to https://render.com → New → Web Service
3. Connect your GitHub repo
4. Settings:
   - **Build command:** `pip install -r requirements.txt`
   - **Start command:**  `gunicorn app:app`
   - **Environment:**    Python 3.11
5. Add environment variable:
   - `DATABASE_URL` = your PostgreSQL connection string
6. Click **Deploy** — your site will be live at `https://your-app.onrender.com`

---

## STEP 5 — DEPLOY TO RAILWAY (alternative, even simpler)

```bash
npm install -g @railway/cli
railway login
railway init
railway up
```

Set `DATABASE_URL` in the Railway dashboard → Variables tab.

## DATABASE SCHEMA

Table: `prediction`
| Column           | Type     | Notes                        |
|------------------|----------|------------------------------|
| id               | Integer  | Primary key                  |
| airline          | String   |                              |
| source_city      | String   |                              |
| dest_city        | String   |                              |
| travel_class     | String   | Economy / Business           |
| stops            | Integer  | 0, 1, 2                      |
| departure_time   | String   |                              |
| arrival_time     | String   |                              |
| duration         | Float    | Hours                        |
| days_left        | Integer  |                              |
| predicted_price  | Float    | In INR                       |
| created_at       | DateTime | Auto UTC timestamp           |

## API ENDPOINTS

| Method | URL        | Description                        |
|--------|------------|------------------------------------|
| GET    | /          | Serves the HTML UI                 |
| POST   | /predict   | JSON body → returns predicted price|
| GET    | /history   | Returns last 10 predictions        |

POST /predict — example body:
```json
{
  "airline": "Indigo",
  "source_city": "Delhi",
  "dest_city": "Mumbai",
  "travel_class": "Economy",
  "stops": "zero",
  "departure_time": "Morning",
  "arrival_time": "Afternoon",
  "duration": 2.5,
  "days_left": 15
}
```

Response:
```json
{ "price": 4325.50, "id": 42 }
```

## INTERVIEW TALKING POINTS

- Model: Random Forest Regressor, R² ≈ 0.98 on test set
- Features: airline, class, stops, duration, days_left, source/dest city, dep/arr time slot
- Preprocessing: one-hot encoding for categoricals, factorize for ordinal stops
- Backend: Flask REST API + SQLAlchemy ORM
- Database: SQLite (dev) / PostgreSQL (prod)
- Deployment: Gunicorn WSGI server on Render
